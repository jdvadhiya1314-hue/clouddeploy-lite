DevOps Best Practices & Security Highlights

How this project adheres to enterprise cloud and CI/CD security principles.

Zero Long-Lived Secrets

Eliminates stored AWS_ACCESS_KEY_ID and secret keys. Uses AWS IAM OpenID Connect (OIDC) identity provider with temporary 1-hour STS credentials.

Least-Privilege Scoping

The IAM Role trust policy strictly validates repository and branch (repo:owner/repo:ref:refs/heads/main). IAM permissions are restricted solely to the target S3 bucket.

Automated Smoke Tests

Before marking a deployment as successful, the pipeline runs a curl smoke test against the live website endpoint, verifying HTTP 200 response and metadata freshness.

Deterministic File Sync

Uses aws s3 sync site/ s3://bucket --delete, guaranteeing atomic updates and automatically removing obsolete or orphaned build files without manual intervention.
